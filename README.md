# RMIT — пробный день в IT-профессии

Попробуй IT-профессию за 10 минут: настоящая рабочая задача джуна, ИИ-тимлид рядом, проверка результата кодом и персональный роадмап по тому, что ты реально сделал(а).

## Что внутри

- **Три профессии с реальными задачами**
  - **Аналитик данных** — «Почему упали продажи?»: SQLite в браузере (sql.js), 512 заказов с заложенной аномалией. Новичок собирает запрос в конструкторе и видит SQL, уровень «есть база» — пишет SQL в редакторе (CodeMirror).
  - **Тестировщик** — «Проверь страницу перед релизом»: корзина с 5 заложенными багами, режим разметки, штраф за лишние отметки.
  - **Фронтенд-разработчик** — «Поправь карточку по макету»: живое превью в iframe, проверка по `getComputedStyle`.
- **Уровень по анкете** (`novice` / `basic`) меняет инструмент и объём поддержки, а не суть задачи.
- **ИИ-тимлид** ведёт по задаче, объясняет термины, не выдаёт ответ, сам пишет, если пользователь застрял.
- **Результат и фидбек**, **рефлексия**, **роадмап на 4 недели**: карта навыков, блок-схема пути, задания с отметками, проверенные ссылки на бесплатные ресурсы, «почему это в плане».
- **«Не знаю, что выбрать»** — подбор профессии по 4 вопросам.

## Принципы

- **LLM — интерфейс и наставник, а не источник истины.** Зачёт задачи, уровень, навыки, план и рекомендации считает код. LLM пишет только живой текст: ответы тимлида, фидбек, резюме роадмапа.
- **Демо не ломается.** У каждого вызова LLM общий таймаут 15 с и откат на заготовки (`src/ai/fallbacks.ts`); JSON от модели валидируется, с одним повтором.
- **Ключ API только на сервере**: прокси `api/chat.ts` (Vercel-функция; в `npm run dev` тот же код через middleware в `vite.config.ts`).

## Запуск

```bash
npm install
cp .env.example .env   # BASE_URL, MODEL, API_KEY — любой OpenAI-совместимый API
npm run dev            # http://localhost:5173
npm test               # тесты логики
npm run build          # проверка типов + сборка
```

Без ключа приложение тоже работает целиком — на заготовленных текстах.

## Структура

```
api/chat.ts                 прокси к LLM
src/types.ts                общие контракты (Profession, Session, Roadmap…)
src/state/                  состояние сессии (React-контекст + localStorage)
src/pages/                  экраны флоу
src/components/             шапка с прогрессом, чат тимлида, UI
src/professions/<id>/       профессия: config.ts, Environment.tsx, checker.ts
src/ai/                     промпты, тимлид, фидбек, роадмап, подбор, заготовки
scripts/gen-analyst-data.mjs генератор данных аналитика (детерминированный)
```

Новая профессия добавляется папкой в `src/professions/` по контракту `Profession` из `src/types.ts` и строкой в `src/professions/index.ts`.

## Стек

Vite, React 19, TypeScript (strict), Tailwind CSS 4, react-router, sql.js, CodeMirror, Vitest. Деплой — Vercel.
